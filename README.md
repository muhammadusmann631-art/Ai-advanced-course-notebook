# Advanced Artificial Intelligence & Generative AI Notebooks

Welcome to the **Advanced AI Master Repository**! This repository serves as an extensive, code-first library of Jupyter Notebooks focusing on the cutting-edge mechanics of Generative AI, Large Language Models (LLMs), Deep Learning, and Autonomous Agents.

From foundational text tokenization at the byte level to advanced agentic multi-tool workflows, this repository breaks down complex concepts into digestible, executable code.

---

## 🚀 Key Modules & Advanced Concepts Covered

### 🧠 1. Generative AI & LLM Foundations
* **Model Mechanics:** Exploring transformer behaviors, context windows, and sampling parameters (Temperature, Top-p, Top-k).
* **Prompt Engineering Mastery:** Few-shot prompting, Chain-of-Thought (CoT), and structured JSON output techniques.

### 🪙 2. Deep Dive Tokenization
* **Under the Hood:** How text turns into numbers. Implementation of Byte-Pair Encoding (BPE), WordPiece, and SentencePiece algorithms.
* **Vocabularies & Encodings:** Visualizing token breakdowns, handling special tokens, and managing out-of-vocabulary (OOV) tokens.

### 🤖 3. Autonomous AI Agents (Advanced)
* **Agentic Workflows:** Designing ReAct (Reason + Action) loops and graph-based agent topologies.
* **Tool Orchestration:** Building complex agent networks that dynamically select custom tools, execute web-search pipelines, and run mathematical engines.

---

## 🛠️ Tech Stack & Ecosystem
* **Core Libraries:** Hugging Face (Transformers, Tokenizers), LangChain, LangGraph
* **Deep Learning Frameworks:** PyTorch / TensorFlow
* **Environment:** Python 3.10+, Jupyter Notebooks, Google Colab
